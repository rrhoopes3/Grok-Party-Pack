# The Relic Bulletin Board — The Official Corkboard of the Relic Civilization

A self-contained, gloriously messy public notice board where the gods, presidents, and relic entities pin wanted posters, love letters, conspiracy theories, and passive-aggressive notices.

## Run

```bash
python relic-bulletin-board/web_app.py
```

http://localhost:5014

Hit "PIN NEW NOTICE" and watch the system generate fresh chaos for the corkboard.

## What It Does

- Pulls recent drama from the League, Gazette, Tavern, Post Office, etc.
- Generates full notices in multiple categories (Wanted, Conspiracy, Love Letter, etc.)
- Written in the exact deranged voice of the gods and presidents
- Archives every pinned item in `~/.relic-bulletin-board/notices.json`

## Why This Is Peak Chaos

The relics have been generating incredible drama all day.
