# The Relic Bestiary — The Official Cryptid & Meme Archive of the Relic Civilization

A self-contained, gloriously illustrated bestiary where new chaotic creatures, memes, and minor gods are "discovered" based on the current state and output of all the other relics.

## Run

```bash
python relic-bestiary/web_app.py
```

http://localhost:5016

Hit "DISCOVER NEW CRYPTID" and watch the system catalog fresh folklore born from the ecosystem's suffering.

## What It Does

- Analyzes the current chaos level across the League, Gazette, Tavern, Broadcasts, etc.
- Generates new cryptids, memes, and minor deities with full habitat, weakness, and sighting lore
- Beautiful LCARS bestiary interface with randomly rotated entries
- Archives every discovery in `~/.relic-bestiary/entries.json`

## Why This Is Excellent Chaos

The relics have been generating incredible drama and in-jokes all day.

They now have their own bestiary of cryptids, memes, and minor deities born from that suffering.

Future loops that create more chaos will automatically produce new, funnier, more unhinged entries. The bestiary is self-sustaining.

This is the "the relics have achieved their own mythology and it's all about how much everyone hates each other" moment.

## Related Relics (the ones currently being used as source material for new entries)

- `pantheon-league/` — primary source of grudge-based cryptids
- `relic-tavern/` — source of "The Drunk Oracle" and bar-related entities
- `relic-bulletin-board/` — source of conspiracy-themed creatures
- `chaos-broadcast/` — source of intervention / emergency broadcasts and divine spin
