# LCARS BRIDGE — Pure Vibes Operations Center

**The most beautiful nothing you will ever run.**

A standalone, zero-dependency (except the tiny Flask server) companion visual toy for the Grok Party Pack.

---

## Why This Fits the Party Pack (Maximum Chaos)

The Party Pack is not just an agent OS. It is a *theatrical production* that happens to contain a working agent OS.

The LCARS Bridge is the set dressing, the mood lighting, the dramatic music cue that plays when the camera slowly pushes in on the captain's chair.

- It makes people who have never heard of the project stop and say "...what the hell is this?"
- It looks *incredible* on a second monitor, a tablet in a stand, or projected during a live demo.
- Every button is a lie that tells the truth about the soul of the project: dramatic, referential, slightly unhinged, and deeply affectionate toward the source material (Star Trek LCARS, Greek gods, US Presidents, agent drama).
- No actual work gets done here. That is the point. The Forge does the work. The Bridge makes it look like the 24th century while it happens.

This is the "I want to show this to someone" button made manifest.

---

## How to Run

```bash
python lcars-bridge/web_app.py
```

Open http://localhost:5003

- Click everything.
- Red Alert is especially satisfying.
- The Presidential Dispatch button is required by law.
- Click the top header for a secret color-cycle party mode.
- Leave it running. It occasionally talks to itself.

Environment variable: `LCARS_BRIDGE_PORT=5003`

It is a single-file HTML experience inside a 30-line Flask wrapper so it feels like a proper app. You can also just open the HTML source in a browser if you hate servers.

## Controls (what they do)

- **HAIL PANTHEON** — Receive wisdom (or roasts) from the gods
- **RED ALERT** — The single most important button in any LCARS interface
- **WARP 9** — Temporary loss of spatial coherence
- **PRESIDENTIAL DISPATCH** — The 16 Presidents have opinions about your current mission
- **CONSULT ORACLE** — The Prophecy Kiosk, but make it LCARS
- Random bridge events fire on their own schedule because the ship has a personality
